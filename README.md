### 🔐 Security, cost & performance
- **Affordable AI**: response caching, a pipeline per request, quotas reserved **atomically in the database** before any model is called
- **Heavy work under control**: concurrency guards (semaphores) on expensive actions, background jobs, client-side limits on parallel requests
- **Server-side by design**: edge functions hold the logic and the keys, inputs are validated, access is enforced at the database level, sensitive data is encrypted
- **Safe AI content**: checks before an answer reaches the user
- **Fast by default**: code-split pages, offline-first where it matters, Lighthouse as a habit
